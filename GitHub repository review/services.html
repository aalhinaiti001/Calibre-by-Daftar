Services

Four clear services. Fixed scope. Clean handovers.

We focus on a few high-impact jobs. We agree the exact scope on a short call, then do the work ourselves.

Service 01

Financial statements

IFRS financial statements, backed by working papers you can trace line by line.

  • Draft statement compilation
  • Audit-ready note disclosures
  • Clean trial balance mapping
Service 02

Audit readiness

We sort your schedules and technical issues before the auditors start, so fieldwork runs faster.

  • Audit gap analysis
  • PBC file compilation
  • Technical accounting remediation
Service 03

Technical review

A straight second opinion on a tricky treatment, estimate, or memo before you commit.

  • IFRS compliance checks
  • Written treatment reviews
  • Defensive response strategy
Also available

Help around deals and one-off projects.

Short jobs with a clear start and end — not open-ended consulting.

Service 04

Transaction support

We clean up and check your numbers so they hold up under buyer diligence, quality-of-earnings, and valuations.

  • Pre-diligence data cleanup
  • Working capital schedules
  • Historical adjustments analysis
Selected topics
  • IFRS technical issues
  • ZATCA readiness support
  • UAE corporate tax coordination
  • Pre-IPO and reporting preparation
  • Finance file repair and simplification
The parameters

A loose scope is where projects stall. We agree the deliverables, exclusions, and key assumptions before any billing. If the scope changes, we stop and re-agree it.
