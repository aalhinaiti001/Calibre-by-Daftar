# UI Kit — Calibre by Daftar landing page

Full-page recreation of the Calibre by Daftar marketing site: sticky header →
hero with the "same candidate, two readers" proof card → core-idea quote →
the Read/Score/Compare/Calibrate method + scorecard mock → outputs bento →
who-it's-for → pilot → contact card → Daftar credibility strip → footer.

- `index.html` — the page. Defaults to the **Midnight** mood; the floating
  "Feel" panel switches mood (Ink / Midnight), type voice, and density.
- Uses Tailwind (CDN) + Lucide (CDN) + Google Fonts, matching the production page.
  Palette is driven by the same two-mood token idea as the design system.

This is a recreation for reference, not production code — swap the Tailwind CDN
for a build step before shipping.
