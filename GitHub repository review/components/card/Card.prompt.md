Bento content surface — the workhorse card for feature grids, outputs, and checklists. Pass a Roman `numeral` for editorial indexing; `highlight` for the one tile you want to pull forward.

```jsx
<Card numeral="I." title="Role-specific scorecard" meta="Weighted • Defensible">
  What "good" means for this role, written down.
</Card>
<Card numeral="VI." title="One-page findings memo" highlight meta="Recommendation">
  A defensible record of what changed and why.
</Card>
```

Body text renders in the serif voice. Re-skins with the active mood.
